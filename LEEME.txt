WEB PARA YADDI - COMO DEJARLA FUNCIONANDO
==========================================

Que hace esta version
- Dos playlists: la de Alexander y la de Yaddi (pestanas arriba).
- Con el boton "Editar listas" y la clave, se busca una cancion por nombre,
  se agrega a la lista que estes viendo y tambien se puede quitar con la X.
- Las canciones suenan con el reproductor de YouTube que va dentro de la web.
- Las listas se guardan en Firebase (gratis), asi se ven iguales desde cualquier celular.

Necesitas hacer 3 cosas: Firebase (paso 1), la clave de YouTube (paso 2)
y subir los archivos a GitHub (paso 3).


PASO 1 - FIREBASE (la base de datos)
------------------------------------
1. Entra a https://console.firebase.google.com con tu cuenta de Google.
2. Pulsa "Crear un proyecto". Ponle un nombre (ej: regalo-yaddi), pulsa Continuar.
   Desactiva Google Analytics y pulsa "Crear proyecto".
3. Menu de la izquierda: "Compilacion" (Build) > "Firestore Database" > "Crear base de datos".
   Elige la ubicacion que te sugiera, elige "Modo de produccion" y pulsa Habilitar.
4. En Firestore entra a la pestana "Reglas". Borra todo lo que hay, pega el contenido
   del archivo firestore.rules (viene en este zip) y pulsa "Publicar".
5. Menu izquierdo: Compilacion > "Authentication" > "Comenzar".
   En "Metodo de acceso" elige "Correo electronico/contrasena", activalo y Guarda.
6. En Authentication, pestana "Usuarios", pulsa "Agregar usuario":
   - Correo: uno inventado, por ejemplo regalo@yaddi.com (no tiene que existir).
   - Contrasena: la CLAVE que van a usar ustedes dos para editar (minimo 6 caracteres).
   Apunta las dos cosas.
7. Arriba a la izquierda pulsa la rueda de engranaje > "Configuracion del proyecto".
   Baja hasta "Tus apps" y pulsa el icono web </>. Ponle un nombre y pulsa "Registrar app".
   Te muestra unos datos: apiKey, authDomain, projectId y appId.
8. Abre index.html y busca el bloque CONFIG (esta cerca del final). Pega esos 4 datos
   entre las comillas de "firebase", y en "usuarioCompartido" pon el correo del punto 6.


PASO 2 - CLAVE DE YOUTUBE (para buscar canciones)
-------------------------------------------------
1. Entra a https://console.cloud.google.com y arriba elige el mismo proyecto que creaste en Firebase.
2. Menu > "APIs y servicios" > "Biblioteca". Busca "YouTube Data API v3" y pulsa Habilitar.
3. "APIs y servicios" > "Credenciales" > "Crear credenciales" > "Clave de API". Copiala.
4. Pulsa la clave para editarla y protegela (importante, porque la clave queda visible en la web):
   - Restricciones de aplicacion: "Sitios web" y agrega  https://TU-USUARIO.github.io/*
     (cambia TU-USUARIO por tu usuario de GitHub).
   - Restricciones de API: "Restringir clave" y elige solo "YouTube Data API v3".
   - Guardar.
5. Pega la clave en index.html, en CONFIG, en la linea youtubeKey: "...".
Dato: es gratis y alcanza para unas 100 busquedas por dia, de sobra para ustedes dos.


PASO 3 - SUBIR A GITHUB
-----------------------
1. Descomprime este zip en tu computador.
2. En tu repositorio de GitHub pulsa "Add file" > "Upload files".
3. Arrastra index.html (y la carpeta musica si la usas). Pulsa "Commit changes".
   Si ya existia un index.html te lo reemplaza, es lo que queremos.
4. Espera 1 o 2 minutos y abre tu pagina. Si no ves cambios, recarga con Ctrl+F5.


COMO SE USA
-----------
1. Abre la web y elige la pestana de la lista (Alexander o Yaddi).
2. Pulsa "Editar listas", escribe la clave y pulsa Entrar.
3. Escribe el nombre de una cancion, pulsa Buscar, y pulsa Agregar en la que quieras.
4. Para quitar una cancion pulsa la X que aparece a la derecha de cada fila.
5. Cualquiera que abra la web puede escuchar las listas, pero solo quien tenga la clave las edita.


SI ALGO FALLA
-------------
- Aviso rosado de "Falta conectar la base de datos": falta pegar los datos de Firebase (paso 1.8).
- "Clave incorrecta": revisa que el correo en usuarioCompartido sea el mismo del paso 1.6
  y que escribas la contrasena que pusiste ahi.
- "No se pudo buscar": revisa la clave de YouTube y que la API este habilitada (paso 2).
  Si dice quota, ya se usaron las busquedas del dia; vuelve a probar manana.
- "No se pudo leer la lista": las reglas del paso 1.4 no estan publicadas.
- Alguna cancion dice que no se puede reproducir: su dueno bloqueo que se vea fuera de YouTube.
  Busca otra version.
